# Layer File List

Lists loaded project layers in a non-blocking dock table.

## Columns

- #
- Group name
- Layer name
- Type
- Provider
- File location
- Open
- Activate
- Visible
- In memory
- Saved
- CRS

## Features

- Refresh table from current project layer tree.
- Open data location in your system file manager.
- Activate any listed layer in the QGIS layer tree.
- Export rows to CSV.
- Sort by clicking column headers.
- Resize and reorder columns interactively.
- Filter rows using built-in column selector and text filter.
- Default CSV path follows current project filename, e.g. `my_project_filelist.csv` beside the `.qgz` file.
